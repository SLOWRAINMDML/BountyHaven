# Bounty Haven · 바운티 헤이븐

**내 우주선으로 사냥꾼을 데려가고, 모두를 다시 데려오는 게임.**

Godot 4.7.2 / GDScript / Compatibility 렌더러로 만든 **플레이 가능한 초기 프로토타입**입니다. 수채·잉크풍 항구 탐험, 양방향 고용 계약, 실제 우주선 조종, 생포 지원, 선내 하우징을 하나의 저장되는 루프로 연결합니다. 단순 기획서나 그림 슬라이드가 아닙니다.

## 실행

1. 이 저장소를 clone하거나 ZIP으로 내려받습니다.
2. **Godot 4.7.2 Standard**에서 `project.godot`를 Import합니다. .NET 버전이나 외부 플러그인은 필요 없습니다.
3. 초기 에셋 import가 끝나면 **F5**로 실행합니다.

```sh
git clone https://github.com/SLOWRAINMDML/BountyHaven.git
cd BountyHaven
godot --headless --editor --path . --quit  # CLI 최초 실행 시 import
godot --path .
```

Windows에서는 기본 `맑은 고딕`, macOS에서는 `Apple SD Gothic Neo`, Linux에서는 `Noto Sans CJK KR` 또는 `NanumGothic`을 찾습니다. **폰트 파일은 동봉하지 않습니다.** Linux에서 한글이 보이지 않으면 시스템에 한글 폰트를 설치하십시오.

## 처음 5분

1. 아래 **길드 · 계약**을 누릅니다. 선장이 길드 앞까지 실제로 걸어갑니다.
2. 기본 선택된 **파일럿으로 지원 → 도망치는 정비공 → 계약 수락**. 바스가 이번 작전에 임시 동승합니다.
3. **항로 조사**에서 기록을 확보합니다. 우주에서 첫 신호가 미리 분석됩니다.
4. **내 우주선 → 함께 휴식 → 조종석 · 출항 준비 → 출항**.
5. 남은 신호에 접근해 **E를 누른 채 분석**합니다. 표적이 드러나면 마우스로 조준하고 사격해 엔진을 멈춥니다.
6. 표적 가까이에서 **E 접현 → 분홍색 보안 중계기 사격 → 표적 근처에서 엄호 → 회수 포드에 접근해 E**.
7. 정산 후 선내로 돌아옵니다. 보수로 가구나 파츠를 구입하고 다음 항구로 향합니다.

선장 주도 계약을 하려면 술집에서 동료를 먼저 고용하십시오. 자금이 부족해지면 출항료와 전투가 없는 **잃어버린 구호 물자** 계약으로 다시 시작할 수 있습니다.

## 구현된 범위

- **항구 2곳**: 녹슨 항구, 첫 현상금 성공 후 개방되는 유리 궤도. 두 번째 항구는 현재 같은 건축 레이아웃의 색감·의뢰 변형입니다.
- **추적자 2명**: 바스는 접현 거리와 엄호 시간, 리오는 스캔과 도주 제한 시간에 실제 차이가 있습니다. 직접 고용한 추적자는 선내 NPC로 남습니다.
- **계약 3종 데이터**: 정비공 생포, 밀수 운반책 생포, 비전투 물자 회수. 두 생포 계약은 기본 전투 구조를 공유합니다.
- **양방향 계약**: 선장이 동료에게 현상금 지분을 주는 방식과, 추적자의 의뢰에 지원해 정해진 파일럿 보수를 받는 방식.
- **전투 모듈 6종 / 장착 4슬롯**: 부스터, 작살, 방향 실드, EMP, 레일포, 제한 보급 정비 드론. 전력·에너지·발열·재사용 대기·시각 하드포인트가 연결됩니다.
- **가구 6종**: 구입·그리드 배치·회전·이동·판매. 통로·출입구·겹침을 검사하고 실제 길찾기 장애물이 됩니다. 효과는 종류별 최대값만 적용합니다.
- **컨디션·회복**: 초기 버전은 선장과 동승자에게 공통으로 적용되는 선내 컨디션 지표입니다. 가구는 휴식 회복량에 영향을 주고, 컨디션 85 이상에서 냉각·에너지 회복 효율이 12% 높아집니다.
- **저장·안전성**: 버전/체크섬/타입·범위 검사, 임시 파일 교체, 이전 저장 백업 복구, 중복 보상·구입 차단. 실패해도 배와 가구가 사라지지 않습니다.
- **적 3종**: 경고 조준 후 사격하는 호위 포함(최대 3), 궤도를 돌다 눈이 빛나면 돌진하는 약탈 드론(최대 2, 추격·접현 중 증원), 도주 표적이 뒤에 뿌리는 근접 기뢰(최대 4, 무장 후 신관 점멸, 사격·연쇄 폭발·EMP 무력화 가능). 비전투 회수 계약에는 나오지 않습니다.
- **우주 환경**: 엄폐물이 되는 소행성 7개(양측 탄환을 막고 충돌 시 튕김), 3단 시차 별빛과 반짝임, 느리게 도는 폐정거장, 가스 행성 고리, 속도감을 주는 먼지 줄무늬, 먼 암석대.
- **VFX**: 수채 번짐 폭발(섬광·안료 번짐·잉크 파편·불꽃·연기·충격파), 총구 섬광, 엔진 분사 입자, 부스터 잔상, 레일포 빔, EMP 번개, 실드 파문, 피격 섬광·화면 흔들림·저체력 비네트, 피해 숫자, 스캔 수렴 입자, 워프 등장. 모두 `scripts/fx/vfx.gd` 한 층에서 그립니다.
- **항구·선내 생활감**: 갈매기 떼, 떠다니는 꽃가루, 물결 반짝임과 부표, 증기, 흔들리는 가랜드 깃발, 현상금 게시판·상자·통·계선주·화분·꼬리 흔드는 항구 고양이, 발자국 먼지, 클릭 지점 파문, 선내 창밖으로 흐르는 별과 빛 기둥.
- **오리지널 합성 효과음**, 한국어 UI, 인게임 조작 안내, 원자로 한도, 일시정지, 정산/여행 기록.

## 아트 구현

**우주 작전은 3D 쿼터뷰로 렌더링합니다** (기획서 12장의 2.5D 방향). 기울어진 원근 카메라, 절차적 로우폴리 모델(크림·녹 도색의 내 우주선과 장착 파츠, 호위함, 표적 화물선, 약탈 드론, 기뢰, 다면체 소행성), 방향광 조명, 성운·별·가스 행성·폐정거장 배경, 3D 입자 VFX를 씁니다. 이동은 평면이고, 선회할 때 기체가 기울어집니다. 장착한 모듈은 정해진 하드포인트에 모양으로 나타나고 사용할 때 실제로 펼쳐집니다. 전투 판정은 기존 2D 시뮬레이션(`BHSpace`)이 그대로 담당하고 `scripts/space3d/`가 그 상태를 읽어 그리기만 하므로 테스트 결과가 화면 방식과 무관합니다. 항구와 선내는 아직 아래 2D 잉크·수채 방식입니다.


현재 화면은 외부 완성 그림을 배경으로 깔아 놓은 것이 아닙니다. `ink_art.gd`가 **직접 작성한 SVG 레이어**를 만들고 Godot에서 최초 한 번 텍스처로 변환합니다. 얇은 선, 투명한 안료 층, 종이 질감, 작은 여행자와 큰 건축물의 대비를 프로토타입에 적용했습니다.

- 하늘·건축·지면·전경은 별도 Sprite2D 레이어입니다.
- 물은 별도 폴리곤+셰이더이고, 안개·등불은 건물 선을 흔들지 않습니다.
- 인물은 머리·팔·다리·외투·스카프가 분리된 컷아웃입니다. 이동/대기 동작과 NPC 길찾기가 있습니다.
- 본문/UI는 종이 셰이더를 통과하지 않습니다.
- **완성된 수채화 원화 수준을 보장하는 최종 아트가 아니라, 교체 가능한 절차적 잉크·수채풍 샘플입니다.** 생성형 이미지 도구로 만든 배경이라고 주장하지 않습니다.

## 오픈소스 활용

요청된 [bobeff/open-source-games](https://github.com/bobeff/open-source-games) 목록에서 **Space Station 14**를 찾아, MIT 라이선스의 `UlamSpiral.cs`를 GDScript로 이식했습니다. 하우징의 가까운 유효 배치 칸 검색과 AStarGrid2D의 가까운 보행 셀 검색에서 **실제로 호출**합니다.

전체 Space Station 14를 Godot로 변환한 것이 아니며, 대규모 우주 게임의 코드·이미지를 무단 복사한 것도 아닙니다. Bounty Haven의 계약·전투·하우징·렌더링은 새로 작성했습니다. 출처·원본 blob SHA·변경 범위·MIT 원문은 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)에 있습니다.

## 검증

```sh
godot --headless --editor --path . --quit
godot --headless --path . --audio-driver Dummy -- --self-test
# 그래픽 드라이버가 있는 환경에서 실제 엔진 화면 6장 캡처
godot --path . --audio-driver Dummy -- --capture-all
# 실제 입력 맵으로 항구 이동 → 출항 → 스캔 → 교전을 실시간 자동 조작하고 5장 캡처
godot --path . --audio-driver Dummy --resolution 1600x900 -- --autoplay
```

`--self-test`, `--capture-all`, `--autoplay`는 사용자 실제 저장을 읽거나 덮어쓰지 않습니다. 결과는 `artifacts/`에 생성합니다. GitHub Actions가 같은 import·테스트·실제 렌더링을 재실행합니다. `artifacts` 디렉터리에는 `.gdignore`가 자동 생성됩니다.

## 아직 포함되지 않은 것

플레이어가 직접 적함 내부를 걷는 별도 지상전, 3D 자유 비행, 멀티플레이, 게임패드/모바일 최적화, 최종 원화·보이스·배경음악, 장편 스토리와 동료 개인 퀘스트, 상점 수익화, 배포용 EXE 자동 출시. 현재 파일은 Godot 소스 프로젝트이며 상용 완성판이 아닙니다.

우주 중 저장/종료는 ‘총알 한 발까지 완전 복원’ 방식이 아니라 **출항 체크포인트 재시작**입니다. 보유 아이템·배치·계약·지불한 출항료는 유지되고 적과 전투는 다시 구성합니다.
