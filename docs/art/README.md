# BountyHaven 아트 문서

시작: [공식 스타일 가이드](CANONICAL_STYLE_GUIDE.md) · [다음 에이전트](NEXT_AGENT_HANDOFF.md) · [프롬프트](PROMPTS.md) · [Godot 조립](ASSET_HANDOFF.md)

`art/canonical/style_contract.json`이 문서와 도구가 공유하는 신규 생성 기준입니다. `art/reference/manifest.json`이 로컬 ZIP에 존재하더라도 그것은 갤러리/보관용 목록이지 이를 대체하는 스타일 규칙이 아닙니다. 과거 MainReset v1 ZIP의 지침을 main 위에 덮어쓰지 않습니다.

기준 문서 배포, 원본 설치, 신규 생성, 레이어 분리, 게임 적용, 실기기 검증은 서로 다른 완료 상태입니다. 원본이 없는 저장소에서도 설정 검사는 통과할 수 있지만 생성용 파일 검사는 실패해야 합니다.
