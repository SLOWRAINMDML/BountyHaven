# 생성 이미지에서 실제 Godot 에셋으로

## 현재 단계

20장의 평면 목표 화면을 보존한 참고 자료 단계입니다. 배경·캐릭터·가구·UI가 분리된 에셋이나 새로운 플레이 씬이 완성되었다는 뜻이 아닙니다. 전체 패키지에는 20개 장면별 계획과 기존 코드 연결점이 포함됩니다.

## 공통 제작 순서

1. 원본 PNG는 `art/reference/originals/`에 v01로 보존합니다.
2. HUD·고정 인물·이동형 가구를 제거하고 그 뒤의 배경까지 복원한 clean plate를 제작합니다.
3. 하늘·원경 건축·지면·전경을 같은 캔버스/원점의 레이어로 분리합니다.
4. 수면·안개·조명·가림 마스크를 각각 제작합니다. 물 효과는 벽과 UI에 적용하지 않습니다.
5. 캐릭터 초상화와 이동용 스프라이트, 가구·문·함선 파츠를 독립 자산으로 만듭니다.
6. 그림에 맞는 보행 다각형·출입구·핫스폿·충돌을 새로 작성합니다.
7. 버튼·글자·가격·진행률은 Godot의 실제 UI와 데이터로 구성합니다.
8. 엔진 실행 캡처와 이동·가림·상호작용 테스트로 검증합니다.

참고 원본은 1672×941이며 현재 게임 뷰포트는 1600×900입니다. 비율을 보존해 미리 보고, 실제 제작은 공통 캔버스를 먼저 확정합니다. 서로 다른 크기의 레이어를 임의로 늘여 맞추지 않습니다. 새 자산의 예정 경로는 `assets/generated/<scene_id>/<version>/`이며 이 폴더의 자산은 아직 생성하지 않았습니다.

## 기존 구현 연결점

| 파일 | 적용할 내용 |
|---|---|
| scripts/world/habitat.gd | 항구·선내 배경, walk_polygon, hotspots, NPC 배치 |
| scripts/world/walker.gd | 분리된 이동용 인물과 애니메이션 |
| scripts/world/furniture.gd | 가구별 외형·배치·회전·충돌 |
| scripts/space/ship_visual.gd | 같은 함선의 외형과 파츠 발동 |
| scripts/space/space_world.gd | 실제 추격·사격·접현·회수 지원 |
| scripts/main.gd | 계약·정산·장비 UI |
| scripts/core/catalog.gd | 실제 의뢰·동료·장비 데이터 |

새 그림의 입구와 길이 기존 좌표와 다르므로 이미지 교체만 하고 충돌 좌표를 그대로 두지 않습니다. 시안의 후방 3인칭 우주 카메라는 기존 평면 전투와 다른 제작 범위입니다.

## 원화에서 수정할 불일치

- 04 생활실: 창밖에 자기 함선 전체가 또 보이는 구도를 정리합니다. 이동 가능한 가구는 빈 배경에서 분리합니다.
- 07~08 전투: 시안 속 미사일·다른 슬롯을 그대로 새 기능으로 취급하지 않습니다. 현재 6개 모듈·4슬롯과 실제 상태를 우선합니다.
- 12 파일럿 계약: 생포 조건과 Dead or Alive의 충돌, 6인 수용 및 임의 보수 비율을 정리합니다.
- 13 명부: 주인공은 조종사입니다. Boarding 점수를 주인공 능력치로 복사하지 않습니다. 기존 voss/rio와 시안 Vass/Mira/Rook의 이름·역할을 분리합니다.
- 14 구금실: 선장과 포로의 Rook 이름 중복을 제거합니다. 안전한 구금·이송이 기본입니다.
- 15 의무실: 개별 부상 시스템은 확장입니다. 현재 공통 컨디션 지표와 혼동하지 않습니다.
- 19 추락 현장: 추락선의 Still Far Enough 표기를 제거하고 별도의 운송선으로 수정합니다. 주인공 소유 함선의 파괴 장면이 아닙니다.
- 20 타이틀: 저장 상태와 무관한 고정 재화·연료 수치를 제거하고 메뉴와 로고를 별도 UI로 만듭니다.

문웨이크·프로스트라인·글래스윈드와 별도 실내 방은 신규 콘텐츠 후보입니다. 이미지가 저장되었다고 그 지역이 구현되었다고 표시하지 않습니다.

## 확인 기준

녹슨 항구 1곳에서 배경 잔상 제거→인물 이동→출입구 접근→NPC 대화→전경 가림→영역 한정 수면 효과를 먼저 검증합니다. 다음은 생활실 가구 배치·통로 차단, 마지막은 함선 모듈·추적자 지원입니다. 이때 기존 프로토타입 캡처를 새 아트 적용 증거로 재사용하지 않습니다.
