## 최신 main의 렌더링 구조는 보존

08d1a52에서 추가된 우주 3D 쿼터뷰를 보존합니다. 항구·선내는 1600×900 기준의 고정 화면 2D 레이어 공간입니다. 우주 작전은 절차적 로우폴리 3D 모델과 기울어진 원근 카메라로 렌더링하며, 시뮬레이션 좌표(px)는 `BHVfx3D.to3d`로 20 px = 1 유닛의 비행 평면에 대응합니다. `BHSpace`의 2D 시뮬레이션과 `scripts/space3d/`의 뷰 분리를 유지합니다. 생성형 원화를 이미 사용했다고 표현하지 않습니다.

2D/3D는 구현 방식이고 승인 그림체는 별도 시각 목표입니다. 이번 지침 정리를 이유로 새 3D 코드를 삭제하거나 우주를 다시 2D로 되돌리지 않습니다. 시안의 후방 구도를 이유로 새 자유 비행/후방 카메라를 무단 도입하지도 않습니다.

## 계속 유효한 조립 계약

sky/city/ground/water/people/furniture/foreground/UI 분리, 캐릭터가 중복으로 배경에 남지 않기, 독립 보행 영역/출입구/핫스폿, 가구 배치 후 길찾기 갱신, 수면에만 물결 적용, UI 텍스트는 후처리 제외를 유지합니다. 원본은 1672x941이므로 비율을 보존해 검토한 뒤 실제 작업 캔버스를 별도로 확정합니다.

새 배경의 길과 입구가 달라지면 `BHHabitat.walk_polygon`과 hotspots도 함께 수정합니다. 기존 우주 전투, VFX, 세이브 및 기능은 보존합니다.

이 문서는 더 이상 독립적인 화풍 프롬프트를 갖지 않습니다. [에셋 조립 계약](art/ASSET_HANDOFF.md)을 참조합니다.
